# Synthetic Data

All generated data in this directory is for a public technical demonstration only.

## Rules

- No PHI or PII.
- No real patient-level records.
- No confidential AbbVie or Snowflake information.
- Generated clinical/scientific values must be explicitly synthetic.
- Public-source reference metadata must be clearly attributed and must not be mixed with fabricated claims about real products.
- Structured and unstructured artifacts must conform to the contracts in `data/schemas/` and `docs/DATA_MODEL.md`.

## Planned directories

- `structured/` — CSV datasets generated in Round 3.
- `documents/` — synthetic scientific documents generated in Round 4.
- `schemas/` — machine-readable contracts defined in Round 2.
